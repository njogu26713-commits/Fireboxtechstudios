Build a World-Class Company Website for FireboxTechStudios

Create a premium, futuristic, fully responsive, and production-ready website for FireboxTechStudios, a software company specializing in Artificial Intelligence, Web Development, Mobile Applications, Cybersecurity, Cloud Computing, DevOps, Automation, APIs, and Custom Software Solutions.

This should not be a simple landing page. It should function as a complete company platform with a powerful administrator dashboard (CMS) where every section of the website can be managed without editing code.

---

Design

Design a world-class interface inspired by modern technology companies.

Requirements:

- Dark futuristic theme
- Black, navy, purple and blue gradients
- Glassmorphism
- Premium typography
- Smooth animations
- Responsive on desktop, tablet and mobile
- SEO optimized
- Fast loading
- Accessibility friendly

Services

- Add service
- Edit service
- Delete service
- Upload icon
- Upload banner
- Upload gallery
- Add pricing
- Add description
- Select category
- Add button text
- Add destination URL
- Feature service
- Publish or hide service

Public users should see professional service cards.

Clicking a service should open either:

- a dedicated service page

or

- another website/app configured by the administrator.
